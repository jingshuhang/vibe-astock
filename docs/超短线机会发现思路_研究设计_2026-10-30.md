# 超短线机会发现思路 · 研究设计

日期：2026-10-30
状态：设计稿（未实现）
范围：`desktop/src/verticals/finance/shortline/` 机会发现层（`opportunities.ts` / `ShortlineOpportunities.tsx`）
证据源：① 外部方法论研究（domain_search 综述）② 本地 18 个交易日实证统计（`/view/shortline_samples`）③ 现有代码勘察

---

## 0. 一句话结论

机会发现的本质不是"识别模式打分"，而是"**在对的环境里找对的模式**"。
现有 `opportunities.ts` 把置信度写死（65/50/70/75/68/60），与环境无关——这是根本缺陷。
本地数据证明：**同一个模式在不同情绪环境下表现天差地别**，环境效应大于模式效应。
发现思路应改为：**环境定调 → 模式查实证表 → 封板时间/板块共振修正 → 输出带实证支持度的机会清单**。

---

## 1. 现有发现逻辑的缺陷（问题定位）

`opportunities.ts` 的 `classifyPattern()` 给五种模式硬编码了置信度：

| 模式 | 现有 confidence | 问题 |
|---|---|---|
| 首板爆发（早封+题材） | 65 | 与环境无关；"题材"只看标签非空 |
| 首板爆发（早封无题材） | 50 | 同上 |
| N字反包 | 70 | 只看"昨日在梯队+今日开板≤1次" |
| 弱转强 | 75 | 只看"昨日开板≥2次+今日一字封" |
| 分歧转一致 | 68 | 只看"昨日开板≥2次+今日早盘封" |
| 龙头接力 | 60 | 只看"≥3板"，风险标"高"但不降分 |

**三个结构性问题**：

1. **置信度是拍脑袋常数**——没有任何历史统计支撑，同模式在退潮期和主升期给一样的分。
2. **环境只体现在 `phase` 字段**（封板率 ≥0.8 强势 / ≥0.6 温和 / 否则分歧），与置信度计算完全脱钩；且这个 phase 与市场状态页的 36 分制、判断条的三灯是**三套不同口径**。
3. **没有负收益视角**——只给胜出的概率暗示，不给"亏多少"的分布。外部研究和本地数据都显示高位模式的负收益占比显著恶化。

## 2. 证据一：外部方法论综述（domain_search）

| 结论 | 数字 | 对设计的含义 |
|---|---|---|
| 次日溢价随板数上升 | 首板 +1.63~1.83% → 三板 +3.13% | 连板档确实有溢价，但见下条 |
| 负收益占比同步恶化 | 首板 9% → 三板 19.3% | **均值上升是少数大肉票拉的**，不是普遍现象 |
| 4 板以上胜率 77.9% | 是方向胜率，非再封概率 | 别把"次日涨"读成"能接力" |
| 2026 生态绝对收益显著下移 | — | 本地窗口（9/30–10/30）均值 +0.98% 基准与此一致 |
| 核心在情绪周期位置 + 竞价/分时确认强度 | — | 数板技巧不是重点；**环境与确认**才是 |

**推论**：置信度不能只用"板数越高越可信"这一条线性逻辑，必须叠加环境与确认强度。

## 3. 证据二：本地 18 个交易日实证（`/view/shortline_samples?date=2026-10-30&days=90`）

窗口：2026-09-30 ~ 2026-10-30，实际可用 18 个交易日（东财只留近一个月明细）。
口径警示（端点自带，必须保留）：样本 = 前一天收盘还封住的票（事后名单），含一字板买不进的、没排除排队买不到的；收益 = 前收→今收等权，无滑点；**是市场现象统计不是策略回测**。
regime 分档：入场日情绪分 = 涨停家数 ×（1+最高连板）×（1−炸板率），三等分切点 low=175.8 / high=221.8。

### 3.1 按环境分层（核心表）

| 打法 | 总样本 | 总胜率 | 总均值 | 情绪强 | 情绪中 | 情绪弱 |
|---|---|---|---|---|---|---|
| 首板打板 | 734 | 50.4% | +0.85% | 54.8% / +1.19% | **36.4% / −0.62%** | 62.4% / +2.28% |
| 首板·早封 | 186 | 56.5% | +1.79% | 54.4% / +0.88% | **41.4% / +0.43%** | 75.0% / +4.26% |
| 首板·尾盘封 | 88 | 46.6% | −0.35% | 46.7% / −1.47% | **26.9% / −1.88%** | 63.3% / +1.90% |
| 首板·涨停数前二行业 | 153 | 56.9% | +2.00% | 63.5% / +3.64% | **44.9% / +0.06%** | 70.0% / +3.51% |
| 连板接力（≥2板） | 207 | 53.1% | +1.43% | 62.9% / +3.18% | **46.4% / +0.44%** | 47.9% / +0.08% |
| 高标接力（≥3板） | 77 | 64.9% | +2.97% | 73.1% / +4.74% | **66.7% / +3.25%** | 54.2% / +0.72% |
| 全体涨停（基准） | 941 | 51.0% | +0.98% | 56.4% / +1.59% | **38.4% / −0.41%** | 58.2% / +1.65% |

### 3.2 封板时间分档（首板专属）

| 封板时段 | 样本 | 胜率 | 均值 | 中位 | 次日再封率 |
|---|---|---|---|---|---|
| 开盘秒板（≤9:35） | 81 | 56.8% | **+2.15%** | +1.96% | 34.6% |
| 9:35–10:00 | 105 | 56.2% | +1.51% | +1.62% | 23.8% |
| 10:00–11:00 | 151 | **41.7%** | **−0.28%** | −1.61% | 11.3% |
| 11:00–14:00 | 230 | 50.0% | +0.97% | +0.03% | 16.5% |
| 14:00 后 | 163 | 52.1% | +0.66% | +0.29% | 12.3% |

### 3.3 三条硬发现

**发现 A：情绪中是最差环境，不是情绪弱。**
全体涨停在情绪中胜率 38.4%、均值 −0.41%，比情绪弱（58.2% / +1.65%）差一大截。
情绪弱（冰点）反而好做首板——因为冰点期首板往往是**新周期起点**，低位试错成功率高。
情绪中 = 过渡/混沌期，方向不明、亏钱效应集中，**宁可不做**。

**发现 B：封板时间非单调，10:00–11:00 是最差档。**
不是"越早封越好"这么简单——开盘秒板 +2.15% 最好，但 10:00–11:00 反而 −0.28%（胜率 41.7%）。
这一档是"早盘冲高没封住、拖到上午中段才勉强回封"的群体，质量最差。
现有代码只用"早封 <10:30"一刀切，**漏掉了 10:00–11:00 这个陷阱档**。

**发现 C：板块共振是首板的最强加分项。**
首板·涨停数前二行业（+2.00%）明显优于泛首板（+0.85%），在情绪强（+3.64%）和情绪弱（+3.51%）都成立。
现有代码只把"题材标签非空"当加分，没有真正做板块聚类统计。

## 4. 发现思路设计：三层架构

```
L1 环境层（已有，复用不另算）        L2 模式层（重构）              L3 确认层（新增）
┌─────────────────────┐      ┌──────────────────────┐      ┌─────────────────────┐
│ 市场状态 36 分闸门    │      │ 模式识别               │      │ 封板时间分档          │
│ 判断条三灯+五字结论   │ ──→  │ ↓                     │ ──→  │ 板块共振（前二行业）    │
│ 竞价分板位 tag       │      │ 查实证表（samples）     │      │ 开板次数/封单强度       │
│ 梯队承接 ladderStats │      │ 环境 × 模式 → 支持度    │      │ 修正后的最终裁决        │
└─────────────────────┘      └──────────────────────┘      └─────────────────────┘
   能不能做、做哪一档              这个模式历史上值多少          这只票比模式均值好还是差
```

### 4.1 L2 核心：置信度从实证查表推导

**关键映射**：今天识别出的模式，就是明天 samples 统计里的类别。
- 今日"首板爆发（早封）" → 明日进入"首板·早封"类别 → 查该类在当前环境的胜率/均值
- 今日"龙头接力（≥3板）" → 明日进入"高标接力"类别 → 查表
- 今日"连板（2板）" → 明日进入"连板接力"类别 → 查表

**环境对齐**（与 samples 口径一致，防前视）：
samples 的 regime 用"入场日（前一交易日）情绪"。机会发现在 D 日看盘、决策 D+1 是否接力，
则应用 **D 日情绪** 查表预测 D+1 表现——正好对应 samples 的"入场日"口径。
D 日情绪 = 当日市场状态/判断条（盘中已有），不另算一套。

**置信度映射表（初始值，标注来源）**：

| 模式 | 情绪强 | 情绪中 | 情绪弱 | 数据来源 |
|---|---|---|---|---|
| 首板·早封 | 55 → 中支持 | 41 → 低/回避 | **75 → 高支持** | samples 3.1 |
| 首板·普通 | 55 → 中支持 | **36 → 回避** | 62 → 中高支持 | samples 3.1 |
| 首板·尾盘封 | 47 → 低 | **27 → 回避** | 63 → 中支持 | samples 3.1 |
| 首板·板块共振 | **64 → 高支持** | 45 → 低 | **70 → 高支持** | samples 3.1 |
| 连板接力（2板） | **63 → 高支持** | 46 → 低 | 48 → 低 | samples 3.1 |
| 高标接力（≥3板） | **73 → 高支持** | **67 → 高支持** | 54 → 中 | samples 3.1 |

> 表中百分数为胜率，直接映射为 confidence（0–100）。
> **情绪中一列几乎全是要回避的**——这是设计上最重要的输出：环境不对，模式再漂亮也不做。

### 4.2 L3 确认层：修正因子

| 因子 | 加/减 | 依据 |
|---|---|---|
| 封板 ≤9:35（开盘秒板） | **+10** | 样本 +2.15%、再封率 34.6% |
| 封板 9:35–10:00 | +5 | 样本 +1.51% |
| 封板 10:00–11:00 | **−15** | 样本 −0.28%、胜率 41.7%，**陷阱档** |
| 封板 11:00–14:00 | 0 | 样本 +0.97%，中性 |
| 封板 ≥14:00 | −5 | 样本 +0.66% 但再封率仅 12.3% |
| 属当日涨停数前二行业 | **+8** | 样本 +2.00% vs 泛首板 +0.85% |
| 开板 ≥2 次后回封 | −5 | 分歧加大，现有代码反而给弱转强 +75，需复核 |

修正后 confidence = 查表值 + Σ修正因子，裁剪到 [0, 100]。

### 4.3 输出形态改造

每个机会不再只给 `confidence: 65` 一个数，而是：

```ts
{
  pattern: "首板·早封",
  confidence: 62,            // 查表 75(情绪弱) + 封板秒板 +10 − 板块外 0 …
  evidence: "情绪弱·首板早封历史胜率 75%、均值 +4.26%（n=44）",
  risk_note: "负收益占比约 25%（1−胜率），中位 +4.97% 但最差 −14%",
  seal_bucket: "开盘秒板",
  in_main_sector: false,
}
```

**必须带读数**（延续三条铁律）：`evidence` 引用样本量与均值，`risk_note` 给负收益侧——不让用户只看到胜率。

## 5. 与验证流的联动（复用不另算）

验证流 `opportunityVerify.ts` 已有六条佐证 gate，本设计不改它的总裁决逻辑，只把 L2/L3 的输出喂给它：

- 环境 gate（市场状态 + 判断条）→ 已实现，**直接复用**
- 模式支持度 → 新增：confidence ≥ 70 才给"支持"，40–69 "观察"，<40 "降级/回避"
- 情绪中 → 不论 confidence 多高，强制降为"观察"或"回避"（发现 A 的落地）
- 梯队接力 gate → 已实现，**直接复用**

**不另算一套原则**：环境读数一律抄判断条/市场状态页的现成结论，本设计只新增"模式×环境查表"这一层。

## 6. 局限性与待验证点

| 项 | 局限 | 待验证 |
|---|---|---|
| 样本窗口 | 仅 18 个交易日（东财只留近月），regime 三等分切点样本量小 | 拉长到 60–90 天后重算，看切点是否稳定 |
| regime 口径 | samples 用入场日情绪分（涨停×板高×炸板率三因子），与市场状态 36 分制、判断条三灯是三套口径 | 需验证三者方向一致性；若不一致，以哪个为准 |
| 环境对齐 | 机会发现用 D 日盘中情绪查表预测 D+1，假设 D 日盘中情绪 ≈ D 日收盘情绪 | 盘中 09:25 与收盘情绪可能背离，需回测盘中快照的预测力 |
| 封板时间档 | 10:00–11:00 陷阱档仅 151 样本，可能是窗口特例 | 换窗口复验；若消失则修正因子作废 |
| 修正因子幅度 | +10/−15/+8 全是拍的，与现有 confidence 同病 | 应由样本分档均值差直接标定，或先跑影子模式积累 |
| 负收益侧 | 只用 1−胜率近似负收益占比，未区分"小亏"与" −14% 大面" | 需拉 worst/median 分布，最好给 VaR 式读数 |
| 外部 vs 本地 | 外部研究（首板 +1.63~1.83%）与本地（+0.85%）量级不一致 | 窗口与生态差异，以本地为准但需持续对照 |
| 不构成投资建议 | 全部是市场现象统计，无成交模拟、无滑点、无排队概率 | 真实打板结果必然更差，界面必须保留口径警示 |

## 7. 实施清单（待排期）

1. **`samples` 映射表模块**：新建 `patternPrior.ts`，把 §4.1 表写成纯常量 + 注释来源；后续可改为从 `/view/shortline_samples` 动态拉（regime cuts 滚动更新）。

3. **封板时间分档 + 板块共振**：实现 §4.2 修正因子；板块共振需对当日涨停池做 `dayContext` 式聚类（可复用 `samples.ts` 的 `dayContext` 思路）。

5. **测试**：情绪中回避、封板 10:00–11:00 陷阱档、板块共振加分、证据读数完整性。
6. **影子模式**：先只输出不改排序，跑一到两周对照，再切正式排序。
